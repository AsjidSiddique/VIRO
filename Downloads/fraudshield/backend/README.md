# FraudShield Backend

FastAPI inference service. Loads the real trained artifacts from `models/` once at startup and
never retrains.

## Setup

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

## Tests

```bash
pytest tests/ -v -s
```

`tests/test_model_integration.py` is the required integration test: it scores the bundled
`models/sample_transactions.csv` through the live model service and compares the result against
`models/sample_predictions.csv` (generated by the original training notebook), printing
`MODEL INTEGRATION TEST: PASSED` or `FAILED`.

## Important: scikit-learn version

`preprocessor.pkl` was pickled under scikit-learn 1.6.1. It **fails to load** under
scikit-learn >= 1.8 due to an internal `ColumnTransformer` change. `requirements.txt` pins the
version for this reason — do not bump it without re-running the integration test against the
new version first.

## Docker

```bash
docker build -t fraudshield-backend .
docker run -p 8000:8000 fraudshield-backend
```
